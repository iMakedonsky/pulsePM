# Meeting notes/checklist template

Please follow this checklist to ensure a productive meeting. Make a PR with a copy of this document for each meeting.

## Checklist to prepare for the meeting
- [ ] What was panned
- [ ] What was finished
- [ ] Questions
- [ ] Feedback
- [ ] All PR comments are addressed or answered: from Alex and AI.
- [ ] PR is ready for review, all CI checks are green
- [ ] Tests are written for the functionality developed
- [ ] You reviewed your own PR already. Every changed file. They all must make sense. Prepare to justify/defend every change. If alternatives were considered, please document them down in docstrings in the classes/functions that you implemented. PRs sent for review should never include files or changes you didn't intend to commit.
- [ ] Follow-up reading topics explored, key concepts/facts added as bullet points.
- [ ] Vocabulary to learn exercised, and 3 compound/complex sentences per word are composed
